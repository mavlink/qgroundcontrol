## Troubleshooting

Most troubleshooting procedures rely on the _QGroundControl_ application log.
[Console Logging](../troubleshooting/console_logging.md) explains how to enable logging categories and capture a log.

Common problems:

- [Connection problems](../troubleshooting/vehicle_connection.md)
- [Parameter Download failures](../troubleshooting/parameter_download.md)
- [Plan Upload/Download failures](../troubleshooting/plan_upload_download.md)
- [Resume Mission failures](../troubleshooting/resume_mission.md)
- [Standard Modes / External Flight Mode failures](../troubleshooting/standard_modes.md)
- [Missing Actuators Page (PX4)](../troubleshooting/actuators.md)
- [Installation, Display and Video problems](../troubleshooting/qgc_setup.md) - _QGroundControl_ fails to start, render, or show video on the host computer.

If your questions are still unresolved, please check the [Support](../support/support.md) page for more information on getting help.
