# Overview

The Overview page provides an at-a-glance overview of your vehicle's configuration status.

The top of the page shows how many of the components that need setup are done, and a checklist of them. Select **Continue setup** to open the next one that still needs attention, or select any component in the checklist to open its setup page.

Below that, a card for each component shows its current settings. Cards with a red border still need setup before flight, and values that need attention are highlighted. Select a card to jump directly to that component's configuration page.
